# Service Plaza — ინჟინერების რეპორტი 2025 vs 2026

დაცული დაშბორდი. შიგთავსი დაშიფრულია AES-256-GCM-ით (PBKDF2-SHA256, 310k იტერაცია),
ამიტომ ამ რეპოზიტორიაში მონაცემები ღია ტექსტად არ ინახება — მხოლოდ salt, IV და ciphertext.

გასახსნელად საჭიროა კოდი, რომელსაც გასცემს ტექნიკური დეპარტამენტი.

გენერირდება ავტომატურად ექსელის ექსპორტებიდან (იხ. პროექტის `scripts/` საქაღალდე).
